<h2><a href=https://www.codewars.com/kata/5a16cab2c9fc0e09ce000097/train/javascript target="_blank">Simple  array rotation</a></h2><h3>6 kyu</h3><p>In this Kata, you will be given an array and your task will be to determine if an array is in ascending or descending order and if it is rotated or not. </p><p>Consider the array <code>[1,2,3,4,5,7,12]</code>. This array is sorted in <code>Ascending</code> order. If we rotate this array once to the left, we get <code>[12,1,2,3,4,5,7]</code> and twice-rotated we get <code>[7,12,1,2,3,4,5]</code>. These two rotated arrays are in <code>Rotated Ascending</code> order.</p><p>Similarly, the array <code>[9,6,5,3,1]</code> is in <code>Descending</code> order, but we can rotate it to get an array in <code>Rotated Descending</code> order: <code>[1,9,6,5,3]</code> or <code>[3,1,9,6,5]</code> etc.</p><p>Arrays will never be unsorted, except for those that are rotated as shown above. Arrays will always have an answer, as shown in the examples below.</p><p>More examples:</p><pre><code class="language-Haskell">solve([1,2,3,4,5,7]) = "A" -- Ascendingsolve([7,1,2,3,4,5]) = "RA" -- Rotated ascendingsolve([4,5,6,1,2,3]) = "RA" -- Rotated ascendingsolve([9,8,7,6]) = "D" -- Descendingsolve([5,9,8,7,6]) = "RD" -- Rotated Descending</code></pre><p>More examples in the test cases. </p><p>Good luck!</p>
